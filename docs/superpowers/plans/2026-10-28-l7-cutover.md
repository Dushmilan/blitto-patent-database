# L7 — Cutover Implementation Plan

> **For agentic workers:** work task-by-task. This layer adds no behaviour, so TDD's red-green loop does not apply: the existing Pest suite is the gate before and after every task. Steps use `- [ ]` for tracking.

**Goal:** Remove the last traces of the Python/React reference application, rewrite the living documentation for the Laravel stack, then rename the repository and local folder so the project is `blitto-patent-database` end to end.

**Issue:** [#66](https://github.com/Dushmilan/BLITTO--MANAGEMENT/issues/66) (closes [#65](https://github.com/Dushmilan/BLITTO--MANAGEMENT/issues/65)).
**Reference:** `BIGGER_PICTURE.md` §6 L7 row, `CONTEXT.md`, ADRs 0001–0006.
**Baseline:** `origin/main` at `c743b60` — L0–L6 merged, Pest **481/481 green** (1452 assertions), Dusk smoke in its own CI job.

## Scope rulings (agreed 2026-10-28)

- **No code changes.** L7 deletes, renames and rewrites prose. If a step wants PHP changed, stop — that is an L8-scope decision, not cutover.
- **History stays verbatim.** `docs/superpowers/**` (plans, specs) and `docs/adr/**` are dated records of what was true when written; they keep their Python/React/`BLITTO_*` mentions. Only *living* docs are rewritten: `Readme.md`, `CONTEXT.md`, `BIGGER_PICTURE.md`, `Agent.md`, `Rules.md`, `backend/README.md`, root `AGENTS.md`.
- **`blitto-theme` stays.** It is live L6 code (`App\Support\Theme`, `partials/theme-script.blade.php`, `ThemeToggleTest`) — renaming it is a behaviour change, not a cleanup. Likewise `BLITTO_CAVEMAN_*` is live tooling config from ADR-0003.
- **`dev-data/seed_snapshot.json` stays.** `DemoDataSeeder` reads it (verified in `database/seeders/DemoDataSeeder.php`). `dev-data/state.json` is the dead Python snapshot and is deleted.
- **`backend/README.md` is replaced.** It is untouched Laravel boilerplate; the root `Readme.md` becomes the product document and the backend README just points at it.
- **Repo/folder rename is last and operator-confirmed.** `gh repo rename` is externally visible and GitHub redirects the old slug; do it only after everything is green.
- **Local cleanup is untracked.** `app/`, `frontend/`, `tests/` still exist on disk in the primary checkout but are already absent from git. Deleting them is a working-copy step, not a tracked change.
- **Dusk is CI-verified.** Run Pest locally; run Dusk only if Chrome + chromedriver are present. CI is the authority for the browser smoke.

## Global Constraints

- All Laravel commands run from `backend/`.
- Verification from the repo root unless stated otherwise.
- Conventional commits, prefix `chore(l7):` / `docs(l7):`.
- Docs must not claim encryption at rest (ADR-0004), JWT/bearer auth (session only), Livewire (ADR-0006) or a Python backend.
- Issue links inside living docs should be relative (`#66`) where possible so the repo rename does not break them; absolute GitHub URLs only where a link must be clickable outside the repo.
- Do not edit `graphify-out/` by hand; regenerate with `graphify update .`.
